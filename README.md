# Sprint 5: Автотесты для Stellar Burgers

Проект содержит автотесты для веб-приложения Stellar Burgers.

## Структура проекта

- `tests/` - директория с тестами
- `locators` - Page Object Model и локаторы
- `conftest.py` - фикстуры pytest
- `requirements.txt` - зависимости

## Тестируемая функциональность

1. **Регистрация**
   - Успешная регистрация
   - Ошибка для некорректного пароля

2. **Вход в аккаунт**
   - Вход по кнопке «Войти в аккаунт» на главной
   - Вход через кнопку «Личный кабинет»
   - Вход через кнопку в форме регистрации
   - Вход через кнопку в форме восстановления пароля

3. **Личный кабинет**
   - Переход в личный кабинет
   - Переход из личного кабинета в конструктор
   - Выход из аккаунта

4. **Конструктор**
   - Переходы к разделам: «Булки», «Соусы», «Начинки»

## Запуск тестов

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск всех тестов в Chrome
pytest --browser=chrome

# Запуск конкретного теста
pytest tests/test_registration.py -v

# Запуск с отчетом
pytest --html=report.html
